## Official PC Requirements

The official PC specs for The Blood of Dawnwalker, per the [Steam store page](https://store.steampowered.com/app/3751260/The_Blood_of_Dawnwalker/):

## Minimum Requirements (1080p target)

| Component | Requirement |
|---|---|
| **OS** | Windows 10, DirectX 12 |
| **Processor** | Intel Core i5-11400F / AMD Ryzen 7 2700X |
| **Memory** | 16 GB RAM |
| **Graphics** | NVIDIA GTX 1060 / AMD Radeon RX 580 (6 GB VRAM) |
| **Storage** | 60 GB available space, **SSD required** |

## Recommended Requirements

| Component | Requirement |
|---|---|
| **Processor** | Intel Core i7-11700K / AMD Ryzen 7 5700X |
| **Memory** | 16 GB RAM |
| **Graphics** | NVIDIA RTX 4060 / AMD Radeon RX 7600 XT / **Intel Arc B580** (8 GB VRAM) |
| **Storage** | 60 GB available space, **SSD required** |

Notable: an **Intel Arc B580** appears in the official recommended list — rare for a AAA release — and both tiers explicitly require **16 GB of RAM** and an SSD.

## Console Performance

Early console footage showed 30 FPS modes, which raised concerns — Rebel Wolves has since confirmed a **day-one patch** adding a **performance mode targeting 60 FPS** on PS5, PS5 Pro and Xbox Series X, alongside quality/fidelity modes. On PC, preview builds were described as solid for frame rate and loading.
